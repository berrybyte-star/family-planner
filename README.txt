FAMILY PLANNER — PWA STARTER

This is a technical starter package based on the current shared-family planner prototype. The working name is a placeholder and can be changed after you choose a final app name.

FILES
- index.html: the planner interface
- manifest.json: installable web app metadata
- sw.js: basic offline caching service worker
- icon.svg: temporary app icon

IMPORTANT NEXT STEPS
1. Test the planner carefully in a browser; this starter has not yet been fully user-tested.
2. Choose and check a final name before reserving it.
3. Host the app on a secure HTTPS website. Service workers and PWA packaging require a secure origin (localhost is okay for local development).
4. Review privacy, data handling, accessibility, language behavior, and store policies before public release.
5. A parent/guardian should help with developer-account setup and any identity-verification or publishing steps. Do not share ID documents or personal account details in this chat.
6. After hosting, use Microsoft's official PWA publishing guidance and PWA Builder to evaluate and package the website for Microsoft Store submission.

CURRENT LIMITATIONS
- Planner data is stored in the browser on that device; there is no account, cloud sync, or cross-device backup.
- This is not yet published or certified by Microsoft.
- The app's Quran references/translations and other content should be carefully verified before public release.
